MED CHECK-IN 2.2.1
==================

Что это
-------
Локальное приложение для двух ежедневных отметок состояния. Системный Windows
PowerShell держит небольшой значок в трее и показывает напоминания в 13:00 и 22:00.
Node.js хранит данные в SQLite, строит графики, делает резервные копии и экспортирует
CSV/JSON.

Установка
---------
1. Распакуйте архив в обычную папку.
2. Запустите INSTALL.bat.
3. При первой установке нужен интернет: установщик скачает официальную закреплённую
   версию Node.js 22.23.1.
4. Установщик удалит файлы предыдущей версии приложения, но не затронет папку данных.
5. После проверки backend и значка в трее приложение откроется автоматически.

Как открыть позже
-----------------
- Дважды нажмите значок Med Check-in в системном трее.
- Или откройте «Med Check-in 2.2» через меню Пуск или ярлык на рабочем столе.

Интерфейс
---------
Интерфейс открывается в Microsoft Edge в режиме приложения: без вкладок и адресной
строки. Для него используется отдельный локальный профиль Med Check-in. Если Edge
недоступен, страница откроется в браузере по умолчанию.

Где находятся данные
--------------------
%LOCALAPPDATA%\MedCheckin2

В этой папке находятся база med-checkin.sqlite, журналы, runtime.json, профиль окна
и ежедневные резервные копии. Переустановка приложения эту папку не удаляет.

Типы записей и шкалы
--------------------
- «День» и «Вечер» — две семантические плановые записи. Рядом с названием
  показывается настроенное время напоминания, но запись принадлежит периоду, а
  не буквальному времени на часах.
- Новая плановая запись начинается с действительно пустыми восемью шкалами:
  настроение, тревога, раздражительность, энергия, концентрация,
  функционирование, качество сна и аппетит. Для сохранения День/Вечер нужно
  заполнить все восемь значений от 0 до 10; приложение не подставляет среднее
  значение. Кнопка «Использовать предыдущие значения» копирует их только по
  явному нажатию.
- «Дополнительно» можно добавлять без ограничения и с любым осмысленным
  подмножеством шкал, симптомов, флажков или заметки. Дополнительные записи не
  заменяют День/Вечер, не закрывают их напоминания и не входят в плановую
  статистику и процент выполнения.

Черновики и история
-------------------
Незавершённая форма сохраняется локально в профиле браузера. После сбоя,
принудительного закрытия или следующего открытия приложение явно предлагает
«Восстановить» или «Отбросить» найденный черновик; успешное сохранение и явный
отказ удаляют его. При переходе с несохранёнными изменениями доступны
сохранение, отказ или отмена.

История доступна за 7, 30, 90 дней, за всё время или за свой период и может
фильтроваться по Дню, Вечеру и Дополнительно. В ней можно добавить пропущенную
плановую запись, не перезаписывая уже существующую. Время наблюдения,
первичной записи и последнего изменения показываются раздельно, если они
известны; старые данные не получают выдуманных времён.

Лечение хранится как полные снимки схемы на дату изменения: препарат, доза,
единица и необязательное время приёма. Поддерживаются исходная схема без даты,
история датированных изменений, добавление, редактирование и удаление.

Резервные копии и перенос
-------------------------
Приложение автоматически создаёт ежедневные резервные копии SQLite и хранит
их по существующему правилу ротации. В настройках доступны «Создать копию» и
«Открыть папку данных». Восстанавливаются только читаемые резервные копии,
созданные приложением и распознанные как совместимая база Med Check-in.
Перед восстановлением текущая база закрывается и сохраняется отдельная
предварительная копия; если замена или повторное открытие не удаются,
предварительная копия остаётся доступной, а приложение не продолжает работу с
неясным состоянием.

Экспорт JSON — это версионированный формат 2.2 с датой экспорта, наблюдениями,
снимками лечения и переносимыми настройками напоминаний. Токены, пути и
временное состояние уведомлений не экспортируются. Перед импортом файл целиком
проверяется, затем показывается предпросмотр с версией формата, количеством
наблюдений и Дополнительно, количеством изменений лечения и диапазоном дат.
Импорт поддерживает только явную операцию «Заменить»: перед подтверждением
создаётся предварительная копия SQLite. Режима Merge, синхронизации и импорта
формата v1 нет.

Диагностика установки
---------------------
Если запуск не подтвердится за 45 секунд, установленная версия останется на месте,
а подробности будут записаны в:
%LOCALAPPDATA%\MedCheckin2\install-diagnostics.txt

Удаление
--------
Запустите windows\uninstall.bat из установленной папки:
%LOCALAPPDATA%\Programs\MedCheckin2\windows\uninstall.bat

По умолчанию медицинские записи сохраняются. Чтобы удалить и их, запустите PowerShell:
powershell -ExecutionPolicy Bypass -File "%LOCALAPPDATA%\Programs\MedCheckin2\windows\uninstall.ps1" -RemoveData

Надёжность
----------
Основная задача Windows запускает backend при входе и перезапускает его после ошибки.
Backend отдельно следит за системным PowerShell-процессом в трее. Watchdog раз в пять
минут проверяет оба слоя. Закрытие окна не останавливает напоминания. Команда «Выйти»
в трее останавливает приложение до следующего входа в Windows или ручного запуска.

Приватность
-----------
После установки приложение не обращается в интернет. API слушает только 127.0.0.1,
защищён случайным локальным ключом, а данные остаются на этом компьютере. Облачной
синхронизации и телеметрии нет. Некорректные шкалы, даты, дубликаты плановых
записей, пустые Дополнительно, несовместимые резервные копии и неподходящий JSON
отклоняются до изменения данных. Переустановка приложения не удаляет медицинские
записи автоматически.

Важно
-----
Это дневник наблюдений, а не медицинская диагностика. Изменения лекарств следует
обсуждать с назначившим врачом.
